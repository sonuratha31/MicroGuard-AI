Model coverage & credits

This is a functional 3D atlas inspired by the supplied reference image. It uses real, separately named anatomical meshes; the screenshot’s exact geometry, texture work and lighting are not available from the image.

Included

2,803 named structures from seven Z-Anatomy GLB collections, regrouped into ten UI layers: skeleton, joints, muscles, nerves, circulation, respiratory, digestive, urinary, endocrine, and lymphatic structures. Reproductive structures and their specifically named blood vessels are excluded. The source model is an adult reference body. It is not a complete representation of every tissue, anatomical variation or microscopic structure.

Skin: this source atlas does not include a separate skin mesh. The normal view shows underlying muscle and anatomy. “Open torso & head” removes selected covering structures. No artificial skin layer is presented as real anatomy.

Microplastic illustration

Colored particles are a synthetic educational overlay. Dots are enlarged for visibility and their locations are illustrative; neither dots nor their number represent measurements, dose, health risk, or a diagnosis. X-ray mode is a rendering style, not a radiograph.

Downloads

Download combined human-anatomy.glb ·

The GLB contains named 3D meshes and a separate illustrative particle group. It can be rotated in Blender or a GLB viewer; it is not rigged for posing or walking. Interactive buttons, screen labels and camera controls are provided by the web viewer. The ZIP contains the local web app and a combined GLB with all seven anatomy collections. It does not need an API key or a paid service.
